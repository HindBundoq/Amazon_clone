# Amazon Homepage Mockup

A full-page structural clone of the Amazon homepage created using pure HTML5 and CSS3 without external frameworks or JavaScript, completed as part of the Orange Coding Academy assignments.

## Project Structure
* `index.html`: Structural markup for the Amazon homepage including navbar, sub-navigation bar, hero section, and product card layouts.
* `amazon-style.css`: Custom CSS stylesheet managing layout structure, color palettes, spacing, and typography.

## Features & Implementation
* Pure CSS layout leveraging **Flexbox** for multi-item header alignment and search bar styling.
* Product section implemented using **CSS Grid** (`repeat(auto-fit, minmax(...))`) for responsive card distribution.
* Multilevel footer structure aligned to resemble Amazon's original user interface design.

## Tech Stack
* HTML5
* CSS3 (Flexbox & Grid)
* Git & GitHub
